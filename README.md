# ORBIT Agent — Android AI Agent

Android-проект на Kotlin с GitHub Actions для автоматической сборки APK. Агент подключается к API, которое указывает пользователь, самостоятельно планирует выполнение задачи, вызывает локальные и Android-инструменты, проверяет их результат и формирует отчёт.

## Что уже реализовано

- **Пользовательский API:** редактируемые URL endpoint, модель и API-ключ. Поддерживается протокол **OpenAI-compatible Chat Completions** с tool/function calling. Для OpenRouter, прокси и других совместимых провайдеров указывается их endpoint и модель. Не любой произвольный API совместим с этим форматом.
- **Ключ на устройстве:** API-ключ шифруется AES-GCM с ключом из Android Keystore. Ключ не хранится в исходниках, APK или GitHub Actions.
- **Agent loop:** запрос модели → tool calls → выполнение → передача результатов модели → следующий шаг. Максимум 2–20 шагов на задачу. Есть отмена, финальный отчёт и короткий контекст последних задач из кэша.
- **Короткие команды:** `/goosearch123 запрос`, `/creagile333 описание`, `/zip333 путь`, `/openapp333 имя`, `/screen333`; обычные задачи на естественном языке тоже поддерживаются. `/help` показывает справку.
- **Автосогласие:** можно включить в настройках. Если выключено, каждый вызов инструмента подтверждается; доступно разрешение всех оставшихся вызовов в рамках текущей задачи.
- **Рабочее хранилище:** отдельная app-specific папка `Android/data/ai.orbit.agent/files/orbit_workspace` (путь зависит от устройства и варианта сборки). Размер используется динамически; жёсткая квота не задана. Есть экспорт всей рабочей папки в ZIP.
- **Файловые инструменты:** список, чтение и запись UTF-8, создание папок, удаление файлов внутри workspace, ZIP и распаковка с защитой от zip-slip.
- **Интернет-инструменты:** веб-поиск через DuckDuckGo HTML и загрузка публичных HTTPS-страниц. Блокируются localhost и базовые диапазоны частных IPv4-адресов.
- **Android-инструменты без root:** открыть URL, запустить доступное установленное приложение, прочитать активный экран, нажать текст, ввести текст, прокрутить экран, выполнить Back и одиночное касание по координатам. Для действий с экраном пользователь вручную включает Accessibility Service в системных настройках.
- **Память задач:** последние задачи хранятся в очищаемом кэше и могут быть отключены настройкой «Запоминать выбор и недавние задачи».
- **Продолжительные операции:** foreground notification помогает Android не усыплять процесс во время работы агента.

## Сборка APK через GitHub Actions

1. Создай пустой GitHub-репозиторий.
2. Загрузи содержимое этой папки в корень репозитория: `.github/`, `app/`, `gradle/`, `gradlew`, `gradlew.bat`, `settings.gradle.kts`, `build.gradle.kts` и остальные файлы.
3. Сделай push в `main` или `master`, либо открой **Actions → Build ORBIT Agent APK → Run workflow**.
4. Открой завершившийся запуск и скачай artifact `orbit-agent-apks`.

В artifact будут:
- `app-debug.apk` — debug APK, подписан отладочным ключом Gradle и подходит для тестовой установки;
- `app-release-unsigned.apk` — release APK без подписи, его нужно подписать перед обычным распространением.

Workflow уже устанавливает JDK 17, Android SDK API 36 и Build Tools 36.0.0. API-ключи в GitHub Secrets для работы приложения не нужны: их вводят в самом APK.

## Первичная настройка

1. Установи `app-debug.apk`.
2. Открой **Настройки**.
3. Укажи точный `API endpoint URL`, `Model ID` и API-ключ. Для типичного OpenAI-compatible API подойдёт полный HTTPS URL `/v1/chat/completions`; если указать адрес, заканчивающийся на `/v1`, приложение добавит `/chat/completions`.
4. Нажми **Сохранить настройки**, затем **Проверить API**.
5. Для автономной работы включи **Автосогласие действий**. Выполнение shell-команд включается отдельной настройкой и по умолчанию выключено.
6. Для работы с другими приложениями открой настройки Accessibility Android и вручную разреши ORBIT.
7. Вернись во вкладку **Задачи** и опиши задачу обычным языком.

## Важные ограничения и модель безопасности

- **Это первый рабочий каркас, не универсальная VM.** Android без root не даёт обычному APK гарантировать полноценную системную виртуализацию, изоляцию процессов или жёсткую квоту диска. `run_command` выполняет `/system/bin/sh` под UID приложения; текущая папка — только начальный каталог, а не контейнерная граница безопасности. Запускаемый процесс может использовать права самого приложения. Не включай shell-команды для недоверенных задач, если не понимаешь последствия.
- Команда Android shell может отсутствовать на конкретном устройстве. C/C++, Rust, Java/Kotlin и другие toolchain не встроены по умолчанию. Агент сможет собирать проект только когда подходящие SDK/компиляторы уже доступны или их можно корректно установить в разрешённой среде. Этот APK пока **не включает** полноценный Linux userspace/PRoot дистрибутив.
- Accessibility — широкое разрешение: агент может видеть текст активного окна и воздействовать на элементы интерфейса. Часть этого текста может быть отправлена выбранному API для анализа. Не используй его в приложениях с чувствительными данными без необходимости.
- Автосогласие включает локальные действия без отдельного диалога. Удаление доступно только внутри рабочей папки, но всё равно может удалить нужные проекты в этой папке.
- Веб-поиск зависит от доступности HTML-страницы DuckDuckGo и может ломаться при изменении её разметки. Поиск — не гарантированная замена официальному Search API.
- Ожидаемый протокол — OpenAI-compatible Chat Completions. Произвольные API с несовместимой схемой, например собственный JSON-формат или отдельный Anthropic/Gemini endpoint, напрямую не заработают без адаптера протокола.
- История хранится в кэше и может исчезнуть при очистке кэша/данных Android. Настройки и зашифрованный ключ хранятся отдельно. Проекты находятся в рабочем хранилище; их экспортируй в ZIP для резервной копии.

## Стек

- Kotlin + Android SDK, min SDK 26, target/compile SDK 36;
- Java `HttpURLConnection` и `org.json` для HTTP/API;
- Android Keystore для локального шифрования ключа;
- GitHub Actions для сборки debug/release APK.

## Структура

```text
app/src/main/java/ai/orbit/agent/
  MainActivity.kt                # UI, settings, approval flow, task memory
  AgentEngine.kt                 # agent/tool-calling loop and tool schemas
  ApiClient.kt                   # configurable OpenAI-compatible endpoint
  WorkspaceTools.kt              # files, ZIP, web and command tools
  AgentAccessibilityService.kt   # optional Android UI automation
  AgentKeepAliveService.kt       # notification while a task is running
  AppSettings.kt                 # local settings
  SecureSecretStore.kt            # AES-GCM + Android Keystore
.github/workflows/build-apk.yml  # CI build and artifact upload
```
