# ORBIT Agent — Android AI Agent

Kotlin/Android-приложение с configurable OpenAI-compatible Chat Completions API, локальным workspace, файловыми инструментами, Android Accessibility, Shizuku (опционально) и C++ JNI-модулем. APK собирается GitHub Actions.

## Что есть в проекте

- **API:** настраиваемые HTTPS endpoint, model ID и API key. Поддерживается OpenAI-compatible Chat Completions с tool calling; произвольные API без совместимого формата не заработают без отдельного адаптера.
- **Ключ:** AES-GCM с Android Keystore. Не добавляй рабочий API key в исходники или GitHub.
- **Отдельный проект на каждую задачу:** `workflow/project-{slug}/`. При совпадении имени к slug добавляется числовой суффикс. Пути инструментов без `workflow/` относятся к текущему проекту.
- **Файлы:** просмотр рабочих папок, текстовый предпросмотр, сохранение отдельного файла через системный диалог Android, упаковка отдельной папки в ZIP, удаление после подтверждения и экспорт всего workspace.
- **Внешние файлы:** нажми «Выбрать папку для файлов агента…». Android откроет системный SAF picker; после согласия ORBIT сможет читать, создавать, менять и удалять файлы только в выбранной папке. При первом запросе агента на внешнюю папку приложение показывает диалог и затем открывает picker. Для создания отдельного файла где угодно можно использовать системное «Сохранить как»; для удаления отдельного файла — выбрать его системным picker и отдельно подтвердить удаление. На Android 11+ нельзя выдать доступ к самому корню `Download` через выбор папки, поэтому используй диалог сохранения/выбора файла для этих действий. Разрешение на выбранную папку можно отозвать в настройках Android.
- **Shizuku:** опциональное подключение через установленный и запущенный Shizuku. Разрешение приложению выдаётся в интерфейсе Shizuku. Отдельный переключатель разрешает модели вызывать `shizuku_command`; он выключен по умолчанию. Запуск Shizuku через Wireless Debugging/ADB даёт UID `shell`, но сам по себе не делает процесс root. Команды shell могут влиять на устройство — включай доступ только при понимании риска.
- **Роль ассистента Android:** в Настройках можно запросить роль `ROLE_ASSISTANT`. При вызове через `ACTION_ASSIST` без переданного текста ORBIT автоматически открывает голосовой ввод. Это использует установленный на устройстве Android speech-recognition provider (обычно Google app / Speech Services by Google), а не отдельный Google Cloud Speech-to-Text API key; постоянного hotword-прослушивания нет.
- **Импорт исходников:** в разделе Файлы можно выбрать до 30 файлов за раз, включая ZIP. Они копируются в `workflow/inbox/`; агенту дано указание изучать загруженные материалы и создавать изменённые/похожие файлы в папке нового проекта, не перезаписывая оригиналы без необходимости. ZIP можно распаковать инструментом `workspace_unzip`.
- **Управление экраном:** при включённом Accessibility агент сначала читает текстовые элементы и описания активного окна, затем может нажать кнопку по тексту, ввести текст, прокрутить и перепроверить результат. Элементы, которые приложение не отдаёт через Accessibility (например, некоторые игровые/графические экраны), могут быть недоступны.
- **Нативный код:** C++ собирается в `liborbitcore.so` для `arm64-v8a`, `armeabi-v7a` и `x86_64`; JNI используется для очистки slug проекта и проверки относительных путей. Основная логика приложения остаётся в Kotlin/DEX. Наличие `.so` и R8 minification не являются гарантией защиты от реверс-инжиниринга.
- **Web:** поиск DuckDuckGo HTML и загрузка публичных HTTPS-страниц. Сторонние сайты могут менять разметку или блокировать автоматические запросы.
- **Автономность:** агент использует цикл tool-calling, передаёт результаты модели и формирует отчёт. Доступно автосогласие, но оно снижает количество предупреждений и повышает риск нежелательных действий.
- **Android UI automation:** чтение доступного текста экрана, нажатия и ввод с помощью Accessibility Service. Разрешение включается пользователем вручную в системных настройках Android.

## Сборка через GitHub Actions

1. Загрузи всё содержимое проекта в корень GitHub-репозитория, включая скрытую папку `.github`.
2. Отправь изменения в `main`/`master` или открой **Actions → Build ORBIT Agent APK → Run workflow**.
3. Скачай artifact `orbit-agent-apks` из завершившегося запуска.

Artifact должен содержать:

- `app-debug.apk` — для тестирования;
- `app-release-unsigned.apk` — релиз без подписи, который нужно подписать перед распространением.

Workflow устанавливает JDK 17, Android SDK API 36, NDK `27.2.12479018` и CMake `3.22.1`. Для сборки требуется Gradle 8.11.1, он загружается Gradle Wrapper-ом. Версии AGP 8.10.0 и Kotlin 2.2.10 согласованы по официальной таблице совместимости. R8 minification включён для debug и release; нативный JNI wrapper сохранён правилами ProGuard.

## Настройка на устройстве

1. Установи debug APK.
2. Открой **Настройки**, укажи HTTPS endpoint, точный model ID и API key.
3. Нажми **Сохранить настройки**, затем **Проверить API**.
4. Выбирай нужные разрешения отдельно: Accessibility, папку внешних файлов, роль ассистента и Shizuku.
5. Начинай задачу с вкладки **Задачи**. Результаты записываются в собственную папку внутри `workflow/`.

## Ограничения и безопасность

- Без root это не виртуальная машина и не полноценный Linux userspace. `/system/bin/sh` запускается с правами приложения, а Shizuku обычно предоставляет UID `shell` — не root.
- Папка `workflow/` хранится в приватной app-specific рабочей области `Android/data/ai.orbit.agent/files/orbit_workspace` (точный путь зависит от варианта APK и Android). Она не совпадает с произвольной папкой Download.
- Внешние файловые операции ограничены SAF-папкой, выбранной пользователем; приложение не получает безусловного доступа ко всему общему хранилищу.
- Команды `run_command` и `shizuku_command` не должны считаться безопасной песочницей. Не включай их для задач, которым нельзя доверять. Shizuku может выполнить больше операций, чем обычный UID приложения.
- Accessibility позволяет считывать содержимое активных окон и управлять элементами UI; часть прочитанного может отправляться настроенному API.
- Назначение ассистентом зависит от версии Android и прошивки. Роль позволяет открыть обработчик задач, но не означает автоматическое голосовое прослушивание.
- Основной код приложения находится в DEX. C++ модуль используется реальным кодом, но не заменяет и не скрывает весь Kotlin-код.
- История недавних задач хранится в кэше и может быть удалена Android. Экспортируй проекты в ZIP для резервной копии.

## Структура ключевых частей

```text
app/src/main/java/ai/orbit/agent/
  MainActivity.kt                 # UI, разрешения, role request, файловый экран
  AgentEngine.kt                  # цикл вызовов API и инструменты
  ApiClient.kt                    # OpenAI-compatible API
  WorkspaceTools.kt               # проекты, SAF, ZIP, web, команды
  ShizukuSupport.kt               # Shizuku binder и UserService
  OrbitShizukuUserService.kt       # shell-команды в Shizuku-процессе
  NativeCore.kt                   # JNI wrapper
  AgentAccessibilityService.kt    # Android UI automation
  AgentKeepAliveService.kt        # foreground notification
  SecureSecretStore.kt            # API key encryption
app/src/main/aidl/ai/orbit/agent/
  IOrbitShizukuService.aidl        # IPC для Shizuku UserService
app/src/main/cpp/
  orbitcore.cpp                    # C++ JNI implementation
  CMakeLists.txt
.github/workflows/build-apk.yml   # CI build and artifact upload
```
